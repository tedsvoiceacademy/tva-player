# TVA Player

**Status:** 🟡 Active
**Last reviewed:** 2026-09-21

## What it does
A Windows audio player and practice recorder for Ted's Voice Academy. It supports independent speed and key changes, mix-side and lead reduction, and named repeat loops for focused practice.

## Stack
Electron + JavaScript + signalsmith-stretch + npm workspaces

## Where it lives
- GitHub: https://github.com/tedsvoiceacademy/tva-player
- Local: `TVA AI Projects/TVA Player`

## Current state
The repository is active and has been cloned locally so it can be opened and worked on from the Project Dashboard.
